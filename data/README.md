## stations_utf8.csv 열

| 열 | 보관소 원본 열 | 대여소 원본 열 | 비고 |
|---|---|---|---|
| id | 관리번호 | (만듦) `rental-5670000-1` | 모두 다름 |
| type | — | — | 보관소 `storage` · 대여소 `rental` |
| name | 자전거보관소명 | 자전거대여소명 | |
| road_address | 소재지도로명주소 | 소재지도로명주소 | 대여소는 빈 값 |
| jibun_address | 소재지지번주소 | 소재지지번주소 | 겹친 공백 정리 |
| gu | (주소에서 추출) | (주소에서 추출) | 의창구 · 성산구 · 진해구 · 마산회원구 · 마산합포구 |
| lat / lng | WGS84위도 / WGS84경도 | 위도 / 경도 | 빈 값 없음 |
| capacity | 보관대수 (거치 가능한 자리) | 자전거보유대수 (빌릴 수 있는 자전거) | 뜻이 달라 화면에서 이름을 다르게 표시 |
| install_year | 설치연도 | — | |
| data_date | 데이터기준일자 | 데이터기준일자 | 보관소 2023-12-31 · 대여소 2026-09-28 |
| open_time / close_time | — | 운영시작시각 / 운영종료시각 | 보관소는 빈 값 |
| closed_days | — | 휴무일 | 대여소: `11월 ~ 3월` |
| fee | — | 자전거이용요금 | 대여소: `무료` |

뺀 열: 값이 전부 비었거나 모두 같거나 쓸 수 없는 값인 열(설치형태 · 차양막 · 공기주입기 · 수리대 · 관리기관 · 전화번호 `000-0000-0000` 등).
