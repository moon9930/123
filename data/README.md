## 합친 규칙 (stations_utf8.csv)
1. 누비자 터미널 2025년 시트에서 "사용함" 454곳 → `type = rental`, `service = nubija`
2. 보관소 283곳 각각에 대해 가장 가까운 누비자 터미널이 **50m 안**이면 그 터미널 행의 `racks`(보관대 수)에 합침 → 261곳
   (한 터미널에 보관소 2곳 이상이 붙은 경우는 0건)
3. 50m 안에 터미널이 없는 보관소 22곳 → `type = storage`
4. 전국 대여소 표준데이터의 창원 1곳 → `type = rental` (service 빈 값)

| 결과 | 곳 수 |
|---|---|
| 누비자 대여소 (보관대 있음 261 · 없음 193) | 454 |
| 보관소만 | 22 |
| 기타 대여소 (낙동강 무료대여소) | 1 |
| **합계** | **477** |
