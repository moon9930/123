# data/

| 파일 | 설명 |
|---|---|
| `shelters_sample.csv` | **예시 데이터 (12행)**. 실제 파일과 같은 구조를 가정해 만든 연습용입니다. 쉼터 이름·주소는 실제가 아닙니다. |
| (넣을 파일) 원본 CSV | 공공데이터포털 「경상남도 창원시_한파쉼터 지정 현황」에서 받은 파일을 여기에 넣습니다. |

## 실제 데이터로 교체하는 순서

1. 원본 CSV를 이 폴더에 넣는다. 한글이 깨지면 EUC-KR(CP949)일 가능성이 크다.
   → "이 파일을 UTF-8로 바꾼 사본을 data/에 따로 저장해줘. 원본은 그대로 둬."
2. "원본의 열 이름을 shelters_sample.csv의 영문 열 이름에 맞춘 UTF-8 CSV 사본을 만들어줘."
3. Supabase에 넣고 "테이블 행 수가 원본 파일 행 수와 같은지 확인해줘."
4. 운영 시간 표기가 lib/hours.js에서 읽히지 않는 형식이 있는지 확인한다(화면에 "확인 필요"로 표시됨).

예시 데이터에는 일부러 형식이 다른 시간(`9시-13시`, `오전9시~오후6시`)을 섞어 두었습니다.
